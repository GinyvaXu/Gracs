# 联机方案（v2：零外置软件优先）

> **默认路径不需要任何联机软件**：开房后把「🔗 邀请」里的地址（或二维码）发给好友即可。
> 本文先讲默认路径怎么选地址，再讲各自适用场景，最后附「高级备选」（传统组网/内网穿透）。

---

## 一、开房者：怎么把地址发给好友

启动后打开房间 → 顶栏 **🔗 邀请**，会列出所有可用地址（按推荐顺序）：

| 地址类型 | 长什么样 | 适用 | 备注 |
|---------|---------|------|------|
| 🏠 **局域网** | `http://192.168.1.4:3000` | 同一 WiFi / 同一路由器 | 最稳最快，无需任何设置 |
| 🌍 **IPv6** | `http://[240e:xxxx:...]:3000` | 双方都有 IPv6（国内宽带大多已支持） | 免端口映射的跨网络直连 |
| 🌐 **公网** | `http://<外网IP>:<端口>` | 路由器支持 UPnP/NAT-PMP | 软件启动时自动映射，成功后才会出现 |
| 🔒 **HTTPS** | `https://192.168.1.4:3001` | 局域网**另一台电脑**要共享屏幕 | 浏览器要求安全上下文；首次需信任自签名证书 |

> 💡 **扫码加入**：房间左下角「📱 扫码加入」或邀请面板里的二维码，手机扫一下直接进；
> 开房者自己可以用 `http://localhost:3000`（本机地址始终可用）。

### 该发哪一个？

1. **在同一 WiFi** → 发局域网地址（首选）
2. **不在同一网络** → 优先发**公网**地址；没有公网地址就发 **IPv6** 地址（前提是双方都有 IPv6）
3. 都没有 → 打开 **🌐 网络** 看诊断建议（通常在路由器开启 UPnP 即可），或使用下面的高级备选

---

## 二、开房者：让公网入口自动出现（推荐）

软件启动时会自动尝试在路由器上打洞（UPnP-IGD / NAT-PMP），**无需手动登录路由器**：

- 成功 → 邀请面板出现「公网」地址，同时日志打印 `✅ 公网入口: http://...`
- 失败 → 网络诊断里会写明原因（常见：路由器关闭了 UPnP、宽带是运营商大内网 CGNAT）

**怎么做能提高成功率：**

| 情况 | 处理 |
|------|------|
| 路由器有 UPnP 开关 | 登录路由器 → 转发/UPnP → 开启 → 软件里点「网络 → 重新检测」 |
| 光猫 + 路由器双层 | 让光猫改桥接（或光猫也开 UPnP），否则会出现两层 NAT |
| 宽带是 CGNAT（诊断会显示） | 用 IPv6；或找运营商申请公网 IPv4（部分省份可免费开通） |
| 校园网/公司网 | 用 IPv6（若分配）；否则用高级备选 |

> **中继兜底**：即使公网入口没打通，只要好友能打开页面（局域网/IPv6/穿透任一方式），
> 画面就能连通——标准链路直连失败时会自动走**开房者电脑上的内置中继**。

---

## 三、好友侧：需要做什么

- 用浏览器打开你发的地址即可（Edge / Chrome / Safari 都行）
- 手机扫码：直接进入观看（手机不能采集屏幕，属系统限制）
- 若提示「无法连接」：确认地址正确、开房者软件在运行、你们在同一网络（局域网地址）或双方都有 IPv6

---

## 四、常见问题排查（按诊断面板）

打开 **🌐 网络**：

| 诊断项 | 说明 | 处理 |
|--------|------|------|
| 局域网直连可用 | 同网络好友可用 | 无需处理 |
| IPv6 公网直连可用 | 跨网络免设置 | 把 IPv6 地址发给好友 |
| 公网端口映射未生效 | 路由器未响应 UPnP/NAT-PMP | 开 UPnP 后「重新检测」；或用 IPv6 |
| 内嵌中继服务运行中 | 严格 NAT 自动兜底 | 无需处理 |
| NAT 类型（深度检测） | full-cone = 打洞极易成功；symmetric = 可能需要中继 | 对称 NAT 下建议用 IPv6/中继 |

## 五、高级备选（默认不需要）

> 适用：内网环境完全封锁 UDP/P2P，且没有 IPv6，也没有公网映射。

### 5.1 Radmin VPN（桌面版内置）

1. 桌面版 → **🌐 网络 → 高级备选 → 打开 Radmin 联机**
2. 未安装时点「安装 Radmin VPN」（首次，会弹 UAC）
3. 开房者「＋ 创建网络」；好友「加入网络」填入同一名称/密码
4. 双方「刷新状态」拿到 `26.x.x.x` 虚拟 IP
5. 好友在「设置 → 服务器」里选「连接朋友的房间」，填入 `26.x.x.x:3000`

### 5.2 蒲公英 / 米西（第三方组网）

所有人装好并加入同一虚拟网络，用虚拟 IP 连接（同事同 Radmin 的用法）。

### 5.3 SakuraFrp 内网穿透（好友零安装）

1. 注册 SakuraFrp（需实名），创建 **TCP 隧道** 映射本机端口（默认 3000），**并开启「自动 HTTPS」**
2. 启动隧道，得到公网域名地址（形如 `frp-oil.com:18565`）
3. 发给好友，在「设置 → 服务器 → 连接朋友的房间」填入该地址（域名自动走 HTTPS）

> ⚠️ 穿透只解决「找到服务器」；媒体是 WebRTC P2P/中继，不走隧道。若严格网络打洞失败，
> 内置中继在开房者电脑上，好友仍需能访问到开房者（穿透已提供）。

### 5.4 IPv6 直连（免装软件）

国内运营商宽带大多已分配公网 IPv6：双方都有 IPv6 时，发 `[IPv6地址]:端口` 即可直连
（服务器默认双栈监听，无需额外配置）。
