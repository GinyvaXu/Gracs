# Radmin VPN 内嵌联机指南（高级备选，Gracs v2.0.0+）

> ⚠️ **v2.0.0 起默认不再需要 Radmin**：优先使用「内置中继 + UPnP 端口映射 + IPv6/局域网直连」。
> 本文仅用于极端内网环境（完全封锁 P2P/UDP 且无 IPv6）的兜底方案。
> 入口：房间顶栏「🌐 网络 → 高级备选 → 打开 Radmin 联机」。

> Gracs 桌面版内置官方 Radmin VPN（免费虚拟局域网，最多 100 台设备），
> 软件内即可完成「安装 → 创建/加入网络 → 用虚拟 IP 直连房间」全流程，**无需**去官网注册、无需公网端口。

## 快速操作（在 Gracs 里）

1. 打开「**🌐 联机**」（首页或房间顶部）
2. 未安装 → 点「**安装 Radmin VPN**」，弹 UAC 点“是”（仅首次）
3. 开房者点「**＋ 创建网络**」：输入网络名称 + 密码 → 把名称/密码发给好友
4. 好友点「**加入网络**」：填入相同名称 + 密码
5. 双方点「**刷新状态**」：看到虚拟 IP（`26.x.x.x`）即成功
6. 开房者确认「服务器设置」为「本机开服」（端口默认 3000）
7. 好友在「服务器设置」切到「连接朋友的服务器」→ 点「**填入我的IP:3000**」→ 保存并重启

> 原理：Radmin 建立虚拟局域网后，开房者的 Gracs 端口（默认 3000）在虚拟网内可直接访问；
> 屏幕画面走 WebRTC P2P 直连，**不经过 Radmin 服务器**，Radmin 只负责让你“找到”对方。

## 手动兜底（自动化失败时）

Radmin VPN 界面：
- 创建网络：菜单「网络」→「创建网络」→ 填名称/密码 → 确定
- 加入网络：菜单「网络」→「加入网络」→ 填名称/密码 → 确定
- 查看 IP：Radmin 主界面「网络」列表里，本机行显示 `26.x.x.x`

## 常见问题

- **提示未安装但点安装没反应**：UAC 被忽略或安装包被安全软件拦截，请手动双击
  `软件目录/resources/Radmin_VPN_2.0.4899.9.exe`（或用 Debug 版里附带的安装包）。
- **刷新看不到 IP**：确认已创建/加入网络，且网络状态为「已连接」；右键托盘图标 → 状态。
- **好友加入后互相 ping 不通**：双方 Windows 防火墙需允许 Radmin VPN（安装时默认已放行）。
- **虚拟 IP 变了**：Radmin 自动分配，重新点「刷新状态」即可。
