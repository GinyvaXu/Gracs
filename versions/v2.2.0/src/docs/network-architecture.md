# Gracs v2 — 网络架构与联机实现

> 一句话：**信令与影院码流经过开房者的服务器；标准链路的画面/声音走 WebRTC 端到端加密（P2P 优先，失败自动中继）；
> 联机不需要任何外置软件**——局域网、IPv6、UPnP 公网映射、内置中继四条路径自动打通。

```
                    ┌──────────────────────────────────────────────┐
   好友浏览器  ◄─────┤ ① 局域网直连      http://192.168.x.x:3000    │
                    │ ② IPv6 直连       http://[240e:...]:3000      │
   好友浏览器  ◄─────┤ ③ 公网端口映射    http://<外网IP>:<映射端口>  ├─────► 开房者电脑
                    │ ④ 内置 TURN 中继  turn:<可达地址>:3478        │      Gracs 服务器
   好友浏览器  ◄─────┤ ⑤ 高级备选        Radmin / 穿透（默认不需要） │
                    └──────────────────────────────────────────────┘
```

## 一、启动时的网络初始化（开房者侧）

服务器启动后异步执行（不阻塞 HTTP 服务就绪）：

1. **枚举本机地址**（`server/net/interfaces.js`）：局域网 IPv4、全球 IPv6（排除虚拟网卡干扰，WiFi/以太网优先）、CGNAT 判定（100.64/10）。
2. **UPnP-IGD / NAT-PMP 端口映射**（`server/net/gateway.js`）：
   - SSDP 发现网关 → 映射 **HTTP 端口(TCP)**、**HTTPS 端口(TCP)**；
   - 读取网关外部 IP（`GetExternalIPAddress`）；
   - 15 秒硬超时，失败只记录原因（"端口映射未生效"），不影响局域网/IPv6/中继；
   - 租约 1 小时，每 20 分钟自动续期，退出时清理映射。
3. **内置 STUN/TURN**（`server/net/turn.js`）：
   - 同一端口提供 STUN Binding 与 TURN（UDP + TCP，端口占用自动顺延）；
   - **临时凭据**：`username = 过期时间戳:标识`，`credential = HMAC-SHA1(secret, username)`，默认 4 小时有效；
   - `relayCallback` 按分配来源选择通告地址：回环客户端 → `127.0.0.1`（同机双开观看/测试），
     其余 → 已知公网 IP（UPnP/STUN）或主局域网 IP，避免多网卡/VPN 环境通告错误地址；
   - 配额：单用户 32 个分配、总量 128；`allowLoopback` 打开（自托管场景需要）。
4. **中继端口映射**：TURN 端口（UDP/TCP）与前 12 个中继端口也尝试通过 UPnP 映射到公网，
   让远程观看者能直接使用中继（best-effort）。
5. **自签名证书**（`server/net/tls.js`）：`selfsigned` 生成，SAN 覆盖本机全部地址，缓存于 `temp/certs/`，
   地址变化或临近过期自动重签；HTTPS 监听在 `端口+1`。
6. **诊断快照**（`server/net/doctor.js`）：把上述状态整理成「人话结论 + 建议」，供客户端 `/api/network` 展示。

启动日志会打印：本机 / 局域网 / IPv6 / HTTPS 地址、公网入口（若映射成功）、中继状态。

## 二、客户端如何拿到连接配置

| 接口 | 作用 |
|------|------|
| `GET /api/config` | 版本、能力（影院模式等）、房间上限、STUN 列表、TURN 是否启用 |
| `GET /api/ice` | **按请求 Host 动态拼装** ICE 服务器：自有 STUN + 公共 STUN + TURN（临时凭据、`turn:当前访问主机:端口`） |
| `GET /api/network[?deep=1]` | 网络诊断报告（深度检测含 NAT 类型，约 3~8 秒） |
| `GET /api/qr.svg?text=` | 服务端生成邀请二维码（SVG，无外部依赖） |
| `GET /api/health` | 健康检查（在线人数、中继统计、网关状态） |

**关键设计**：TURN URL 用**客户端实际访问用的主机名**（`req.headers.host`）拼装。
好友用局域网 IP 打开，就得到 `turn:192.168.x.x:3478`；用公网 IP 打开就得到 `turn:<外网IP>:3478`；
用 IPv6 打开就是 `turn:[240e:...]:3478` —— 无需服务器猜测客户端位置。

客户端在 `进入房间前` 预取 ICE 配置（避免首帧连接缺中继），TURN 尚未就绪时自动重试（6 秒 ×3），
拿到新配置后对失败连接自动重建。

## 三、标准链路（WebRTC）

### 3.1 连接模型
- 每个对端按方向拆成独立单向连接：`outPcs`（我发送）/ `inPcs`（我接收）；
  影院模式的系统声音单独一条 `cinema-audio`（仅音频）。
- **共享者主动 offer**：新成员加入 → `member:joined` → 共享者对该成员建立出站连接；
  观看者被动应答，天然无 glare。座位互换（对方也共享）互不影响。
- 观看者需要重建时发送 `signal {type:'renegotiate'}`，共享者重新 offer。

### 3.2 ICE / NAT 穿透
- ICE 服务器来源：自有 STUN（对观看者而言是"外部"服务器，可探测其公网映射）+ 公共 STUN + 内置 TURN。
- 严格网络自动走中继；中继内容仍是 DTLS-SRTP 加密，服务器只转发密文。
- 连接失败自动重建（带 8 秒冷却），远端描述就绪前的候选先缓存后补交。

### 3.3 画质与自适应
- 编解码优选：AV1 → VP9 → H.264 → VP8（按双方能力交集，`setCodecPreferences`）。
- 采集：`contentHint`（文字/电影 detail，游戏 motion）、分辨率与帧率约束。
- 每条连接独立码率上限：`sender.setParameters({ encodings[0].maxBitrate, degradationPreference })`。
- 自适应（`client/js/stats.js`）：每 2 秒采样 `availableOutgoingBitrate` / 丢包 / RTT，
  AIMD 调节每位观看者的上限（跌落 0.7，回升 1.08），并受「总上行预算」约束。
- 新观看者入房主动请求关键帧。

### 3.4 带宽估算（mesh）
- 上行 ≈ `Σ 每位观看者当前码率`（自动档受预算约束）；512×N 观众上限 12 人（房间上限）。
- 电影档 1080p30 目标 10 Mbps；游戏档 1080p60 目标 14 Mbps；省流档 720p30 目标 2.5 Mbps。

## 四、影院模式（WebCodecs + 服务器中继）

详见 [cinema-mode.md](cinema-mode.md)。要点：
- 共享端编码（WebCodecs）→ 二进制批次 → Socket.IO → 服务端 `volatile` 转发 → 观看端解码 → canvas 渲染。
- 声音仍走 WebRTC（Opus，仅音频）。
- 服务端不解析码流内容，仅转发 + 路由反馈/关键帧请求。

## 五、安全与隐私

- **标准链路**：DTLS-SRTP 端到端加密，服务器看不到内容（P2P 或 TURN 中继均加密）。
- **影院模式**：画面经服务器转发（可按需启用传输层加密）；声音仍为 WebRTC 端到端加密。
- **TURN 凭据**：临时（默认 4h），由服务端密钥签发；密钥持久化于 `temp/turn-secret.txt`（或环境变量 `TURN_SECRET`）。
- **中继限制**：用户/总量配额、单包上限 64KB、空闲 120 秒回收；源地址一致性校验。
- **信令层**：单包大小限制（SDP/ICE ≤ 256KB，影院批次 ≤ 1MB），房间成员校验。

## 六、与旧方案（VPN/穿透）的对比

| | v1（组网/穿透） | v2（本方案） |
|---|---|---|
| 用户操作 | 所有人装 Radmin/蒲公英，或开服者装穿透工具 | 开房后把地址/二维码发给好友，**零安装** |
| 画质影响 | VPN 中继带宽小、抖动大 → 画质不稳 | 直连优先；中继由本机提供，带宽可控 |
| 依赖 | 第三方服务（免费额度、注册、实名） | 无；全部能力内嵌 |
| 失败兜底 | 换另一个工具 | 内置诊断 + 中继 + 高级备选入口 |

> 高级备选（Radmin / SakuraFrp）教程见 [fri-network.md](fri-network.md)。
