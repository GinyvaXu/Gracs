## 二、施工项

1. **桌面版资产替换**：
   - `assets/icon.ico` ← `gracs.ico`；`assets/icon.png` ← `gracs-256.png`；`assets/tray.png` ← `tray-32.png`。
   - Electron 主进程的托盘/窗口/安装器图标均从这些文件读取（`desktop/main.js` 使用 `nativeImage` / electron-builder 配置），替换后重新打包验证。
2. **PWA 资源替换**：`client/assets/icon-192.png`、`icon-512.png`、`icon-maskable-512.png` ← 对应 staged 文件；`client/manifest.webmanifest` 无需改动（路径一致）。
3. **favicon**：`client/index.html` 目前引用 `/favicon.svg`（旧的手绘矢量）。三种处理方式任选：
   - 保留旧 favicon（与新图标并存的过渡方案）；
   - 改用 PNG：把 `favicon-32/64.png` 放入 `client/` 并把 `<link rel="icon">` 指向 `favicon-32.png`；
   - 重绘 `favicon.svg`（新配色 + G+播放），保持矢量。
4. **⚠️ 更新 `scripts/gen-icon.mjs`（重要）**：该脚本目前是**程序化绘制**旧图标，`npm run icon` 会重新生成并**覆盖**上面替换的全部资源。两种做法：
   - **推荐**：把新 artwork 作为基准源（例如 `scripts/icon-source.png` ← `gracs-1024.png`），把脚本改为"读源图 → 生成各尺寸"（可引入 `sharp` 作为 devDependency；或保留零依赖自研 PNG 缩放）；
   - 或：按新配色/新形状同步修改绘制逻辑（工作量更大，不推荐）。
   在脚本更新前，请先不要执行 `npm run icon`。
5. **验证清单**：
   - `npm start` → 浏览器页签图标、托盘图标、窗口图标；
   - `npm run dist:debug` → 产物 exe 在资源管理器中的图标；
   - PWA：`manifest.webmanifest` 的三个图标在安装后显示正常（maskable 安全区无裁切）；
   - 浅色 / 深色系统主题下托盘图标都清晰。
6. **收尾**：CHANGELOG 记一条（如 `更换应用图标（G+播放 · 清新薄荷）`）；README 顶部可加图标展示。

  `docs/design/02-ai/recolor.mjs`、`export-project-assets.mjs` 重新生成。
